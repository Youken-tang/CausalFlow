# Goods 物资保障仿真

这是一个物资保障链的离散事件仿真系统，模拟从生产者到消费者的完整物资流转过程。

## 快速运行

```bash
cd /path/to/causal_open_source
export PYTHONPATH=$PWD/python:$PYTHONPATH
cd examples/goods
python3.14t main.py
```

查看输出：

```bash
# 查看CSV日志（365行数据）
head -50 goods_log.csv
tail -20 goods_log.csv
```

## 系统概述

模拟一个三级物资保障体系：

```
生产者(Producer) -> 一级仓库 -> 二级仓库 -> 消费者(Consumer)
```

### 实体类型

1. **生产者(Producer)** - KindId=0
    - 接收需求订单并生产货物
    - 统计累计发货量

2. **仓库(Warehouse)** - KindId=1
    - **一级仓库(First Level)**: 从生产者补货，向二级仓库发货
    - **二级仓库(Second Level)**: 从一级仓库补货，向消费者发货
    - 具有库存管理功能
    - 低于安全库存时自动补货

3. **消费者(Consumer)** - KindId=2
    - 定期产生需求（每1个时间单位）
    - 发送普通订单或紧急订单
    - 普通订单：向多个仓库平均分摊
    - 紧急订单：选择最优的2个仓库

### 消息类型

- `T_NeedGoods` (0): 需求订单消息
- `T_GoodsArrive` (1): 货物到达消息

### 订单类型

- **普通订单**: 需求量服从正态分布，使用普通运输速度
- **紧急订单**: 需求量更大，使用紧急运输速度

## 文件说明

- `vector2d.py` - 二维向量类，用于表示实体位置
- `vehicle.py` - 运输工具类，定义普通和紧急运输速度
- `order.py` - 订单消息和共享状态类
    - `Order`: 订单事件
    - `OrderState`: LP共享状态
- `producer.py` - 生产者实体
- `warehouse.py` - 仓库实体
- `consumer.py` - 消费者实体
- `goods_simulator.py` - 仿真控制器
- `main.py` - 主程序入口

## 输出

程序运行后会生成`goods_log.csv`文件，包含所有实体在每个时间点的状态：

CSV格式：

```
时间,实体类型,实体ID,数值
```

- Producer: 累计发货量
- Warehouse: 当前库存量
- Consumer: 累计收货量

## 仿真逻辑

### 消费者需求

1. 消费者每1个时间单位产生一次需求
2. 10%概率产生紧急需求，90%概率产生普通需求
3. 普通需求：向最近的2个二级仓库平均分摊
4. 紧急需求：向评分最高的2个二级仓库发送（考虑运输时间）

### 仓库管理

1. 接收需求订单时：
    - 检查库存是否足够
    - 计算运输时间
    - 发送货物到达消息
    - 减少库存

2. 库存低于安全阈值时：
    - 普通模式：向多个供应商分摊补货请求
    - 紧急模式：向最近的供应商发送补货请求

### 距离和时间

- 实体位置使用二维坐标表示
- 运输时间 = 距离 / 速度
- 使用欧氏距离计算实体间距离
